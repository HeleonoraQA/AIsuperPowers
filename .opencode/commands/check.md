# Check - Полная проверка

Выполняет полный цикл проверок перед завершением задачи:
1. `ruff check . --fix` - линтинг с автоисправлением
2. `ruff format .` - форматирование кода
3. `pytest -q` - запуск всех тестов

**Использование:** `/check`

После выполнения обязательно проверить результаты и зафиксировать их в `docs/progress.md` согласно AGENTS.md §6.
