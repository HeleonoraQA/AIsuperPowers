# Lint - Проверка и форматирование

Быстрая проверка стиля кода:
1. `ruff check . --fix` - автоматическое исправление ошибок линтера
2. `ruff format .` - форматирование по PEP 8

**Использование:** `/lint`

Только для файлов с кодом `.py`. Файлы документации (`.md`, `.json`) не проверяются.
