# Инструкция пользователя Recipe Finder

## Описание программы
Recipe Finder — CLI-приложение для подбора блюд на основе имеющихся продуктов. Программа находит рецепты, которые можно приготовить из введённых ингредиентов, с возможностью фильтрации по способу приготовления.

## Запуск программы

### Способ 1. Интерактивный режим (рекомендуется)
1. Откройте терминал в папке проекта `AIsuperPower`
2. Выполните команду:

```bash
# Windows PowerShell
$env:PYTHONPATH="src"; python -m recipe_finder
```

```bash
# Linux/macOS
PYTHONPATH=src python -m recipe_finder
```

3. Программа предложит ввести ингредиенты через запятую:
```
Введите ингредиенты через запятую: картофель, масло, соль
```

### Способ 2. С передачей аргументов
Можно сразу передать ингредиенты без интерактивного ввода:

```bash
# Windows PowerShell
$env:PYTHONPATH="src"; python -m recipe_finder --ingredients "картофель, масло, соль"
```

## Работа с программой

### Результат работы
Если найдены подходящие блюда, программа выведет меню:

```
Предлагаемое меню:
1. Картофель в духовке — в духовке (совпадение 100%)
```

При частичного совпадении также будет указано, чего не хватает:
```
1. Овощи в духовке — в духовке (совпадение 50%); не хватает: перец, чеснок
```

Если блюд не найдены:
```
Подходящих блюд не найдено.
```

Если список ингредиентов пуст:
```
Список ингредиентов пуст.
```

### Сохранение ингредиентов
После каждого ввода программа автоматически сохраняет список ингредиентов в файл `data/ingredients.json`. Это позволяет сохранить историю введённых продуктов.

## Параметры запуска

| Параметр | Описание | Значение по умолчанию | Пример |
|---|---|---|---|
| `--ingredients` | Список ингредиентов через запятую | Интерактивный ввод | `--ingredients "яйцо, молоко, масло"` |
| `--method` | Фильтр по способу приготовления | Без фильтра | `--method stove` |
| `--limit` | Максимальное количество блюд в меню | `3` | `--limit 5` |
| `--min-match-ratio` | Минимальная доля совпадения ингредиентов (0-1) | `1.0` (только полное совпадение) | `--min-match-ratio 0.5` |
| `--recipes` | Путь к базе рецептов | `data/recipes.json` | `--recipes custom.json` |
| `--store` | Путь для сохранения ингредиентов | `data/ingredients.json` | `--store my_ingredients.json` |

## Способы приготовления
- `steam` — на пару
- `oven` — в духовке  
- `stove` — на плите

## Советы по использованию

1. **Для поиска блюд, которые можно приготовить сразу** — используйте режим по умолчанию (полное совпадение). Просто введите имеющиеся продукты.
2. **Если ничего не найдено** — попробуйте частичное совпадение: `--min-match-ratio 0.5`. Программа покажет блюда, где есть хотя бы половина ингредиентов, и укажет, чего не хватает.
3. **Для конкретного способа готовки** — используйте фильтр `--method`. Например, если хочется готовить только на плите.
4. **Ингредиенты можно вводить в любом порядке** — программа сама нормализует их (пробелы, регистр).
5. **Повторяющиеся ингредиенты** — игнорируются автоматически.

## Примеры использования

```bash
# Найти блюда только на плите
$env:PYTHONPATH="src"; python -m recipe_finder --ingredients "яйцо, молоко, масло, соль" --method stove

# Поиск с частичным совпадением
$env:PYTHONPATH="src"; python -m recipe_finder --ingredients "картофель, масло" --min-match-ratio 0.5

# Показать больше вариантов
$env:PYTHONPATH="src"; python -m recipe_finder --ingredients "овощи, масло" --min-match-ratio 0.3 --limit 5
```

## Требования
- Python 3.11 или выше
- Только стандартная библиотека (дополнительные зависимости не нужны)

## Устранение неполадок

| Проблема | Решение |
|---|---|
| `ModuleNotFoundError: No module named 'recipe_finder'` | Необходимо указать `PYTHONPATH=src` (или `$env:PYTHONPATH="src"`) |
| `Список ингредиентов пуст.` | Вы ввели только пробелы или пустую строку. Введите хотя бы один ингредиент через запятую |
| `Подходящих блюд не найдено.` | Попробуйте использовать частичное совпадение с `--min-match-ratio` ниже 1.0 |
| Ошибка при загрузке файла | Проверьте целостность `data/recipes.json`. Файл должен соответствовать строгой схеме проекта |
